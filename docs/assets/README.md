# Presentation assets

- `teaser.svg` and `method-overview.svg` are vector exports of the paper figures, with outlined fonts and embedded images. Data, labels and scales are unchanged.
- `demos/spreadsheet-4k.mp4` and `demos/three-suns-en-2k.mp4` are the original-resolution recordings shown in the README. They retain their original playback speed.
- `demos/three-suns-2k-results.json` records the game measurements and checksums. [Recording details](../DEMOS.md) describe the inputs and timing scope.
- `demos/browser-demo-results.json` records the three refreshed Pro-4B demonstrations, including the new 4K spreadsheet recording. These measurements are separate from the paper benchmarks.
- `OCTICONS-LICENSE` preserves the license for the GitHub mark used in the paper PDF.

The code repository keeps two representative videos and two core figures.
